## **🛒 E-Commerce Order API**

A backend API service to create and manage customer orders in a PostgreSQL database. Built with Node.js, Express, and PostgreSQL, this service allows storing order details (including customer metadata) once a payment is completed.

## **✨ Features**
Backend Features

RESTful API endpoints for creating orders

Integration with PostgreSQL using pg library

Order metadata stored as JSON (customer details, shipping info, etc.)

Auto-generated orderId in format WOWKID<id>

Error handling for invalid/missing fields

Ready for scaling and integration with frontend/payment modules

**🛠 Tech Stack**
Backend

Node.js - Runtime environment

Express.js - Web framework

PostgreSQL - Database

pg - PostgreSQL client for Node.js

dotenv - Environment variable management

## **🔧 Prerequisites**
